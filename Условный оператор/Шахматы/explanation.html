Логика задачи: какие фигуры могут перейти из одной клетки в другую

📐 Базовая идея: координатная система

Доска 8×8. Клетки нумеруются x (1..8) — столбцы (A..H), y (1..8) — ряды (1..8).

Фигура стоит в (x, y). Хотим проверить, может ли она пойти в (new_x, new_y).

dx = |new_x - x| — расстояние по горизонтали
dy = |new_y - y| — расстояние по вертикали

В задаче все фигуры играют за белых, ход выполняется на свободной доске и без взятия фигуры соперника.

🏰 Ладья (Rook)

def rook(self, new_x, new_y): return "YES" if self.x == new_x or self.y == new_y else "NO"
Правило: dx == 0 ИЛИ dy == 0
Ладья ходит по прямой: либо тот же столбец (x не меняется), либо тот же ряд (y не меняется).

Пример: ладья на e4 (5,4). Ходит на e1, e8, a4, h4 — везде, где x=5 или y=4.

⛪ Слон (Bishop)

def bishop(self, new_x, new_y): return "YES" if abs(self.x - new_x) == abs(self.y - new_y) else "NO"
Правило: dx == dy
Слон ходит по диагонали. На диагонали изменение x и y одинаковое по модулю.

Пример: слон на c1 (3,1). Диагонали: b2, d2, a3, e3... — везде |dx| = |dy|.

👑 Ферзь (Queen)

def queen(self, new_x, new_y): return "YES" if self.rook(new_x, new_y) == "YES" or self.bishop(new_x, new_y) == "YES" else "NO"
Правило: (dx == 0 ИЛИ dy == 0) ИЛИ (dx == dy)
Ферзь = ладья + слон. Просто объединяем два правила через OR.

🤴 Король (King)

def king(self, new_x, new_y): return "YES" if max(abs(self.x - new_x), abs(self.y - new_y)) == 1 else "NO"
Правило: max(dx, dy) == 1
Король делает ровно 1 шаг в любую сторону. И dx, и dy ≤ 1, и хотя бы одно = 1.

Почему max, а не dx+dy?
dx+dy==1 даёт только 4 направления (вверх/вниз/влево/вправо).
max(dx,dy)==1 даёт все 8 соседей + диагонали.

🐎 Конь (Knight)

def knight(self, new_x, new_y): dx, dy = abs(self.x - new_x), abs(self.y - new_y) return "YES" if (dx == 2 and dy == 1) or (dx == 1 and dy == 2) else "NO"
Правило: (dx=2 И dy=1) ИЛИ (dx=1 И dy=2)
Конь — единственная фигура, которая «перепрыгивает». Ход буквой «Г»: 2 по одной оси, 1 по другой.

Важно: Порядок не важен, поэтому проверяем оба варианта.

Пешка (Pawn)

def pawn(self, new_x, new_y): dx, dy = new_x - self.x, new_y - self.y if dx == 0 and dy == 1: return "YES" if dx == 0 and dy == 2 and self.y == 2: return "YES" return "NO"
В этой задаче пешка белая и ходит без взятия:
  • Белая пешка идёт вверх, то есть y увеличивается.
  • Обычный ход: dx = 0, dy = 1.
  • Первый ход на 2 клетки: dx = 0, dy = 2, стартовая линия y = 2.
  • Диагональный ход не подходит, потому что по условию хода с взятием нет.
Пример: из E2 в E3 пешка может, из E2 в E4 тоже может, из E2 в F3 не может.

Итоговый метод all

def all(self, new_x, new_y=None): if new_y is None: new_x, new_y = self.coord(new_x) else: new_x, new_y = int(new_x), int(new_y) pieces = [ ("King", self.king(new_x, new_y)), ("Queen", self.queen(new_x, new_y)), ("Rook", self.rook(new_x, new_y)), ("Bishop", self.bishop(new_x, new_y)), ("Knight", self.knight(new_x, new_y)), ("Pawn", self.pawn(new_x, new_y)), ] can_move = [name for name, answer in pieces if answer == "YES"] return "\n".join(can_move) if can_move else "Nobody"
Метод проверяет все 6 фигур, оставляет только те, для которых ответ YES, и печатает их английские названия. Если список пустой, выводится Nobody.

💡 Почему именно так написано?

  • Математика вместо переборов — формулы O(1), не нужен массив 8×8
  • Чистая геометрия — шахматы — это геометрия на сетке, dx/dy её идеально описывают
  • Нет магических чисел — 1, 2, 8 понятны из контекста (шаг, двойной шаг, размер доски)
  • Формат вывода простой — печатаем названия подходящих фигур, а если таких нет, печатаем Nobody
  • Тестируемость — каждый метод — чистая функция (x,y)→bool, легко покрыть тестами
